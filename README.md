# Хранилище файлов для сайтов

Заготовка для раздачи файлов, которые не принимает Тильда: видео (mp4), PDF, крупные картинки.

## Как пользоваться

1. Положить файл в репозиторий (репозиторий должен быть публичным).
2. Ссылка для сайта:
   `https://cdn.jsdelivr.net/gh/<пользователь>/<репозиторий>@main/<файл>`
3. Если файл заменяется под тем же именем — сбросить кеш CDN:
   `https://purge.jsdelivr.net/gh/<пользователь>/<репозиторий>@main/<файл>`
   Надёжнее — заливать под новым именем.

## Что важно помнить

- Лимит jsDelivr — 20 МБ на файл.
- Отдаёт правильный тип файла: video/mp4, application/pdf, image/jpeg,
  и поддерживает докачку частями — видео играет в Safari на iPhone.
- `.docx` и подобные офисные файлы jsDelivr блокирует (403).
  Для них — прямая ссылка:
  `https://raw.githubusercontent.com/<пользователь>/<репозиторий>/main/<файл>`
- Это временное решение для демо и согласований. На боевом сайте клиента
  файлы должны лежать на его стороне: свой сервер или объектное хранилище
  (например, Yandex Object Storage).

Файлы проекта TaxSmart удалены — заказчик перенёс их в свой бакет.
